# ThermoRawMetaDump_gui
Simple Python GUI for [ProteoWizard's](http://proteowizard.sourceforge.net/) ThermoRawMetaDump to extract metadata from Thermo Fisher .raw LC-MS files for Windows.
The path to the ProteoWizard installation has to be included in PATH.
The python script is converted to a Window's executable for easier use with the py2exe module.
